# 🚀 Portfolio Website (React + Vite)

This is a modern portfolio website built using **React + Vite**.
It is fast, responsive, and easy to customize.

---

## 📦 Getting Started (First Time Setup)

Follow these steps when you download or clone this project for the first time:

### 1️⃣ Install Node.js

Make sure Node.js is installed on your system.

👉 Download from: https://nodejs.org

To check installation:

```bash
node -v
npm -v
```

---

### 2️⃣ Open Project Folder

* Extract the downloaded ZIP (if needed)
* Open the folder in **VS Code** or any code editor

---

### 3️⃣ Install Dependencies

Open terminal inside the project folder and run:

```bash
npm install
```

This will install all required packages.

---

### 4️⃣ Run the Project

Start the development server:

```bash
npm run dev
```

---

### 5️⃣ Open in Browser

After running, you will see something like:

```
Local: http://localhost:5173/
```

👉 Open this URL in your browser

---

## 🛠️ Project Structure

```
├── public/        # Static files
├── src/           # Main source code
│   ├── components # UI components
│   ├── pages      # Page sections
│   └── assets     # Images, styles
├── index.html     # Entry HTML file
├── package.json   # Dependencies & scripts
```

---

## ✏️ Customization

* Update content inside `src/`
* Replace images in `assets/`
* Modify components as needed

---

## ⚠️ Common Issues

### ❌ npm not found

👉 Install Node.js and restart terminal

---

### ❌ Port already in use

Run with different port:

```bash
npm run dev -- --port=3001
```

---

### ❌ CSS warnings (like @import order)

👉 Not critical, but you can fix by placing `@import` at the top of CSS files

---

To create a production build:
